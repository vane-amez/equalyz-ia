# Equalyz
Plataforma web para comparar productos entre tiendas nacionales e internacionales y ver el
costo real antes de comprar, con aranceles, envío y garantía.

## Idea
Muchas personas dudan entre comprar en una tienda local o importar. Equalyz muestra el precio
final, el tiempo de entrega y la garantía lado a lado, y separa los datos verificados de los
estimados.

## Funcionalidades
- Buscador por enlace de producto
- Comparador lado a lado con puntuación por colores
- Ventajas y desventajas de cada opción
- Tabla de factores clave (precio final, entrega, garantía, satisfacción)
- Módulo para emprendedores y comunidad (diseñados en Stitch)

## Proceso
1. Definimos la idea con un LLM, que nos hizo preguntas para aclarar requisitos.
2. Escribimos el prompt (ver `PROMPT.md`).
3. Diseñamos las pantallas en Google Stitch con una paleta de Coolors.
4. Iteramos: botones mates, menos texto, más espacio entre secciones.
5. Construimos la versión HTML/CSS.

## Herramientas
Google Stitch, Coolors, HTML, CSS y JavaScript.

## Nota
Los precios, reseñas y puntuaciones son datos de ejemplo, no datos reales.
